# 风格切换 (style_modes)

## 两个轴

### 1. `style_mode` — 语气风格

| 值 | 何时用 | 行为 |
|---|---|---|
| `conservative` | 默认；用户没明确要求"直断"时 | 多用"倾向、容易、建议关注"；少用强断 |
| `direct` | 用户说"直接给结论 / 不要中间过程 / 详细直断" | 直接写结论、五年断事、可执行建议 |

### 2. `assertiveness` — 断言强度

| 值 | 句式示例 |
|---|---|
| `low` | "财星偏弱，整体倾向稳健积累。" |
| `medium`（默认） | "财运是稳健积累型，35 岁前后可能有提级窗口。" |
| `high` | "33-43 岁是这辈子最重要的财运十年；2026 一定会做一次重大决策。" |

`high` 仅在 `style_mode=direct` 且用户明确要求"详细直断"或"哪一年一定 / 可能"时启用。

---

## 触发规则

| 用户原话信号 | 推荐设置 |
|---|---|
| "帮我看下八字" / "分析下我的命" | `direct + medium`（默认） |
| "保守点说 / 别说太满 / 给个参考" | `conservative + low` |
| "直接给结论 / 不要中间过程 / 详细点 / 哪一年会发生什么" | `direct + high` |
| 用户在前文已点出 mode | 沿用 |

---

## Mode 影响

| 栏目 | conservative | direct |
|---|---|---|
| 资料确认 | 必出 | 必出 |
| 结论 | 一段含"倾向" | 直接点格局核心 + 主要矛盾 |
| 事业/财运/感情 | 偏分析 + 风险点 | 适配赛道 / 模式 + 不适配方向 |
| 五年断事 | 倾向描述 | "一定发生 / 可能发生"二分 |
| 建议 | 偏抽象 | 偏具体可执行 |
| 尾注 | 必出 | 必出 |

---

## 不变项（无论 mode）

- 任何排盘事实必须来自 engine。
- 不写"用了什么方法"。
- 不写 emoji（除非用户要）。
- 默认中文，跟随用户语言。
- 即便 `assertiveness=high`，也禁止伪精确预测（"姓张的人"、"住北边的"、"34岁三月份"）。事件保持类别级。
